# 健康状態の確認（Health Check Report）

このサイトは GitHub Pages で公開する静的なページだけでできています。サーバーもデータベースもないため、動き続けているかを見張るしくみは要りません。

ここで言う「健康」は、次の 2 つが通っていることです。

1. 書き出したページが確認をすべて通ること
2. 公開先でページが表示されること

| 項目 | 状態 | 根拠 |
|---|---|---|
| 書き出し | 正常 | `hugo` のエラー 0、警告 0 |
| ページの中身の確認 | 正常 | `run_checks.py docs` の 7 種類すべて OK |
| 確認プログラム自体 | 正常 | 単体テスト 70/70 件が通過 |
| 公開先の表示 | 未確認（まだ push していない） | 本人が push したあとに確かめる |
| GitHub Actions の `check` | 未確認（まだ push していない） | push すると動く |

## まとめ

公開の準備はできています。公開先の表示と GitHub Actions の確認は、本人が push したあとに確かめます。
