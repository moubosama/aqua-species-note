# 範囲の決定（Scope Document）

入力にした文書: 意図の整理 `intent-statement.md`、実現性の評価 `feasibility-assessment.md`、制約の一覧 `constraint-register.md`（と `raid-log.md` の課題 I-1〜I-5）。回答は scope-definition-questions.md の Q 番号で示します。

## 1. この作業で仕上げるもの（範囲内）

| # | 仕上げるもの | 中身 | 出どころ |
|---|---|---|---|
| S-1 | 種ページのテンプレート（型） | すべての種ページに共通の骨組み（見出しと順番、要点の表、繁殖記録の比較表、出典と信頼度の表示、更新日）を Hugo に組み込む | Q1 |
| S-2 | CW111 ページの移し替え | ゼブリーナのページを新しい型に並べ直す。中身は今のものを使う。有料ガイドへの誘導枠と仮の文言は外す | Q1、Q3 |
| S-3 | 調査と執筆の手順書 | 調べる → 突き合わせる → 書く → 確認する → 公開する、を毎回同じ品質で回す手引き。品質の基準と、AI の要約を原文と見比べる確認手順を含む | Q1、実現性の評価（著作権・AI の確認） |
| S-4 | 次の10種類の候補 | 候補のリストと、選ぶ基準・選んだ理由 | Q1 |
| S-5 | 更新履歴ページ | 公開・更新の記録と、月1回のまとめを載せる場所 | Q2、意図の整理（知らせ方） |
| S-6 | 検索対策 | 構造化データ・OGP・サイトマップ。本公開まで noindex は外さない | Q2 |
| S-7 | 用語集ページ | 種ページに出てくる用語の説明 | Q2 |
| S-8 | 比較ページ | 種をまたいで繁殖記録などを比べるページ。今は1種なので、仕組みと最初の形まで | Q2 |
| S-9 | 既存の不具合の修正 | ヘッダーのサイト名リンク、種の一覧の英語タイトル、使っていない空ページ、404 ページ、表の幅 | Q8 |

## 3. 進める順番（Q4）

1. 型（S-1）を作る。既存の不具合（S-9）もこのとき直す。
2. ゼブリーナのページ（S-2）を新しい型に並べ直し、型がうまく働くか確かめる。
3. 更新履歴・用語集・比較ページ・検索対策（S-5〜S-8）を足す。
4. 手順書（S-3）と次の10種類の候補（S-4）を作る。

## 4. 期限と費用

- **期限: なし**（Q5）。
- **費用の上限: 月3,000円まで**（Q6）。論文の購入なども含む。今は0円で回っている（constraint-register.md C-08 を更新）。
