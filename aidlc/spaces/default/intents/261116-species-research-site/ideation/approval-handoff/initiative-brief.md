# 企画のまとめ（Initiative Brief）

もとにした文書: `intent-statement.md`、`stakeholder-map.md`、`competitive-analysis.md`、`feasibility-assessment.md`、`constraint-register.md`、`scope-document.md`、`intent-backlog.md`。チームづくり（team-assessment）とラフ案（wireframes）の段階は今回の計画に入れていません。回答は approval-handoff-questions.md の Q 番号で示します。

## 1. 何をするか

珍しい熱帯魚を1種類ずつ、世界中の記録（論文・海外の繁殖報告・飼育記録・動画）から深く調べ、日本語で出典つきの1ページにまとめて公開するサイトを作る。

- **問題**: 珍しい種の記録は世界中に散らばっていて、日本語で一か所にまとまっていない。買う人・殖やしたい人が判断の材料を持てない（intent-statement.md）。
- **読者**: 国内の中・上級の愛好家（繁殖を目指す人を含む）と、研究者・学生。
- **成功の物差し**: 公開した種の数、検索からの訪問数、読者からの反応。目標値はまだない。
- **関係者**: 本人1人が作り、決める。情報提供者と読者の意見を参考にする（stakeholder-map.md）。

## 2. 市場で勝てる点

- 扱う種の数では海外 DB や国内の図鑑に勝てない。**深さで勝負する**（competitive-analysis.md）。
- 差別化の柱: 繁殖記録の比較表、生息地の水のデータ、出典と信頼度の表示、分かっていないことの明記。
- 弱点: 写真（転載しないため）。情報提供者と海外の研究プロジェクトに使用許可を頼む。

## 3. 実現性とリスク

| 面 | 判定 | 要点 |
|---|---|---|
| 技術 | 実現できる | 今の Hugo サイトと GitHub Pages のまま |
| 運営 | 条件つき | 月1種の目標に対し、CW111 の深さは重い |
| お金 | 続けられる | 費用は月3,000円まで。収入は当てにしない |
| 法律・著作権 | 条件つき | 引用と AI 要約の確認手順を要件で決める |

**いちばん大きなリスク（月1種が続かない）への備え: 手順書に「浅く調べる版」と「深く調べる版」の2段階を作り、種によって使い分ける。次の種でかかった時間を測る**（Q1）。

## 4. 範囲

今回の作業で仕上げるもの（scope-document.md、intent-backlog.md）:

1. 種ページの型（テンプレート）と、最初のレビューで見つかった不具合の修正（Must）
2. ゼブリーナのページを新しい型に並べ直す。有料ガイド枠は外す（Must）
3. 更新履歴（Should）、検索対策（Should）、用語集（Could）、比較ページ（Could）
4. 調査と執筆の手順書（浅い版・深い版）（Must）と、次の10種類の候補（Must）

今回やらないこと: 有料販売、広告・アフィリエイト、「水面」との連携、2種類目以降の執筆、本公開。

## 5. 体制と期限

- 本人1人。Hugo のテンプレートはこの作業の中で一緒に作る。
- 期限なし。費用は月3,000円まで。
- 撤退条件: 本公開した日から1年たっても検索からの訪問が月100クリック未満なら方針を見直す。

## 6. 判断

**Go（進める）。** 技術とお金の面で妨げはなく、最大のリスクには手順書の2段階で備える。収益化の条件は未定のまま進める（Q2）。

## Assumptions & Open Questions

- 成功の物差しの目標値、収益化を考え始める条件は未定。
- 写真・図の扱いと、短い引用をどこまで認めるかは要件の段階で決める。
- masukoap とレプスキの URL は未着。
- 著作権と景品表示法の説明は一般的な理解で、専門家には確かめていない。
