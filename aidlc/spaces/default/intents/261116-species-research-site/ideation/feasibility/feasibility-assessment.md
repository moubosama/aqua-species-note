# 実現性の評価（Feasibility Assessment）

入力にした文書: 意図の整理 `intent-statement.md`、市場調査の `competitive-analysis.md`・`market-trends.md`・`build-vs-buy.md`。回答は feasibility-questions.md の Q 番号で示します。

**結論: 続けられる見込みはある。ただし「月に1種類」のペースは CW111 の調べ方のままでは重く、いちばん大きなリスクになる。お金は当面ほぼ入らない前提で、撤退条件で区切る。**

## 1. 技術面 — 問題なし

| 観点 | 評価 | 根拠 |
|---|---|---|
| 公開の仕組み | 問題なし | 今の Hugo サイトと GitHub Pages のまま。サーバも費用も要らない（build-vs-buy.md の決定 C） |
| ページのテンプレート | 小さな作業 | 既存のテンプレートは3ファイルだけ。Hugo のテンプレートはこの作業の中で一緒に作る（Q11） |
| note との併用 | 問題なし | 本体はサイト、要約と告知は note（build-vs-buy.md） |
| 調査の道具 | すでにある | CW111 で、論文・Planet Catfish・海外フォーラム（ブラウザ）、YouTube 字幕（yt-dlp）、日本のブログを調べた実績がある |

## 2. 運営面 — いちばんのリスクはペース

- 目標は**月に1種類**（Q1）。1年で12種類。
- CW111 は、論文1本、海外の繁殖報告とフォーラム8件、動画12本、日本の飼育日記86回分、店のブログ十数件、ブラジルの法令まで調べ、参考文献は48件に達した（既存ページ `site/content/species/corydoras-cw111-zebrina.md`）。
- この深さを毎月続けられるかは、まだ分からない。1種にかかった時間の記録がないので、**次の種で時間を測る**必要がある（仮説：CW111 と同じ深さなら、月1種はかなり厳しい）。
- 対策の候補（範囲・要件の段階で決める）:
  - 種によって深さを変える（記録の少ない種は短く終わる）
  - 調査と下書きに AI を使い、引用と数字は原文で確かめる（Q3）。確認の時間は残る。
  - 調べる手順を決め、毎回同じ順で回す（依頼の「手順書」）

## 3. お金 — 当面は支出だけ、収入はほぼない

### 支出

- 今のままなら0円（GitHub Pages と note の無料の範囲）。
- **上限は範囲の段階で決める**（Q10）。論文の購入や独自ドメインが必要になったら、そこで判断する。

### 収入の見込み（すべて仮定）

最初の版では有料販売・広告・アフィリエイトを入れない（意図の整理）。収益化を考え始める条件はまだ決まっていない（Q5）。以下は、収益化した場合の**大きさの見当をつけるための仮の計算**で、どの数字も確かめていません。

| 仮定 | 控えめ | 楽観 |
|---|---|---|
| 公開した種（1年後） | 12種（Q1 のペースどおり） | 12種 |
| 1種あたり月の閲覧数 | 100 | 500 |
| 月の閲覧数の合計 | 1,200 | 6,000 |
| 表示広告の収入（1,000閲覧あたり） | 100円 | 300円 |
| **広告の月収（見当）** | **約120円** | **約1,800円** |

- 珍しい種は検索する人そのものが少ない（仮説）。閲覧数は、種名ごとの検索数を測るまで当てにならない（市場調査 market-trends.md：日本の市場規模・飼育人口の数字は見つかっていない）。
- 広告だけでは費用を賄う程度にとどまる見込み（仮説）。依頼にある PDF・Kindle 版や「水面」の会員のほうが、1人あたりの単価は高い（仮説）。
- **結論: 収入を目的にした計画は立てられない。** 撤退条件（下の 5）で区切りながら、読者の反応と検索数を見て判断する。

## 4. 法律・著作権 — 方針はあるが細部が未定

| 論点 | いまの方針 | 残る注意点 |
|---|---|---|
| 他の人の記録の使い方 | 「引用してこちらでまとめる。記載はAIでまとめてこちらで確認する」（Q9、本人の言葉のまま） | 日本の著作権法では、引用には「自分の文章が主で、引用は従」「引用部分をはっきり分ける」「出典を書く」が求められる（一般的な理解。専門家の確認はしていない）。AI の要約が原文の言い回しに近すぎると、引用の範囲を超えるおそれがある。確認の手順は要件の段階で決める |
| 数字・事実 | 出典を付ける | 数字や事実そのものは著作物ではない（一般的な理解）。表にまとめる自由度は高い |
| 写真・図 | 未定（Q9 の回答は文章について） | 依頼文では「転載しない。写真は自撮りか許可を得たもの」。要件の段階で確かめる |
| 原産国の輸出規制 | 合法かどうかは断定しない。分かることと分からないことを書く（Q8） | ブラジルの IN 10/2020 のように規則が変わる（market-trends.md）。ページに確認日を書く |
| 日本の規制 | 種ごとに確かめて書く（Q8） | 外来生物法・動物愛護法などに当たるかは未調査（market-trends.md） |
| 将来の広告・アフィリエイト | 最初の版では入れない | 入れるときは「広告」の表示が要る（2023年10月からの景品表示法のステルスマーケティング規制。一般的な理解） |

## 5. 撤退・見直しの条件

- **1年たっても検索からの訪問が月100クリック未満なら、方針を見直す**（Q6）。
- 期間の起点（テスト公開の終わり、つまり noindex を外した日か）は、範囲の段階で決める。

## 判定

| 面 | 判定 |
|---|---|
| 技術 | 実現できる |
| 運営（ペース） | 条件つき。次の種で時間を測り、深さとペースを調整する |
| お金 | 支出は0円で続けられる。収入は当てにしない |
| 法律・著作権 | 条件つき。引用と AI 要約の確認手順を要件で決める |

## Assumptions & Open Questions

- 1種あたりの所要時間は記録がない。次の種で測る。
- 収入の計算の数字（閲覧数・広告単価）はすべて仮定で、確かめていない。
- 費用の上限と、収益化を考え始める条件は未定（Q10、Q5）。
- 写真・図の扱いと、短い引用をどこまで認めるかは要件の段階で決める。
- 著作権・景品表示法の説明は一般的な理解で、専門家には確かめていない。
