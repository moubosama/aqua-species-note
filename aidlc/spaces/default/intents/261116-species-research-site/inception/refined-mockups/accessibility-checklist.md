# 読みやすさ・使いやすさの確認表（Accessibility Checklist）

目標は WCAG 2.1 AA です。もとにした文書: `requirements.md`（FR3.5、NFR6、FR9.2）、`team-practices.md`（Testing Posture）。

それぞれの項目を、**機械で確かめる**（書き出したページを調べるプログラム、FR9.2）か、**人が目で確かめる**かに分けます。要件のレビューで、表の横スクロールと狭い画面での表示の確かめ方が決まっていないと指摘されたため、ここで分けて決めます。

## 機械で確かめる（FR9.2 の確認プログラムに入れる）

| # | 項目 | 確かめ方 |
|---|---|---|
| M1 | 全ページの `<html>` に `lang="ja"` がある | HTML を読んで属性を確かめる |
| M2 | 見出しが h1 から順に並び、レベルを飛ばさない（h2 の次にいきなり h4 にならない） | 見出しのレベルの並びを確かめる |
| M3 | 1ページに h1 は1つだけ | h1 の数を数える |
| M4 | 要点の表・繁殖記録の表が、横スクロールの枠（`scroll` クラス）の中にある | 表の親の要素のクラスを確かめる |
| M5 | CSS で `.scroll` に `overflow-x:auto` があり、表に `display:block` がない（D5 の再発確認） | `style.css` の文字列を確かめる |
| M6 | 表に `<caption>` があり、見出しのセルが `<th>` | 表の構造を確かめる |
| M7 | 横スクロールの枠に `tabindex="0"` と名前（`aria-label`）がある | 属性を確かめる |
| M8 | 目次が `<nav aria-label="目次">` に入っている | 要素と属性を確かめる |
| M9 | 画像があるときは `alt` がある（いまは画像なし） | `<img>` の `alt` を確かめる |
| M10 | ページの `<meta name="viewport">` がある | head を確かめる |

## 人が目で確かめる（公開前と、型を変えたとき）

| # | 項目 | 確かめ方 |
|---|---|---|
| H1 | 幅 375px（スマートフォン）で、本文が横にはみ出さず、表は表の中で横にスクロールできる（NFR6、FR3.5） | ブラウザの開発ツールで幅を 375px にして種ページを見る |
| H2 | 要点の表が本文の幅いっぱいに広がっている（D5） | 幅 1024px 以上で種ページを見る |
| H3 | 暗い配色でも文字が読める | 端末を暗い配色にして見る |
| H4 | キーボードだけで、目次 → 章、［n］ → 参考文献、表の横スクロールができる | Tab と Enter、矢印キーで操作する |
| H5 | 文字を 200% に拡大しても、本文と表が読める | ブラウザで拡大して見る |

人が確かめる項目は、手順書（FR6）の「確かめる」段階の確認項目に入れます。
