## 1. 種ページ（全種共通の型）

章の並びは案A（Q1）。番号は見出しに付けます（Code Style の「章は番号付き」）。

```
[ヘッダー] 熱帯魚 種類別ノート  ............ (押すと /aqua-species-note/ へ。FR3.1)
--------------------------------------------------------------
[h1] コリドラス・ゼブリーナ（CW111）
[学名] Hoplisoma sp. (CW111)（旧 Corydoras）   (属名だけ斜体。FR1.6)
[日付] 公開日 2026-11-16 / 更新日 2026-11-16   (FR1.5)

[要点の表] (8項目、全種で同じ順。値がなければ「記録なし」か「未確認」。FR1.2、Q3)
  流通名 | 分類（学名の状態） | 産地 | 大きさ | 水温 | 水質（pH など） | 繁殖 | 相場（時期つき）

[目次] (押すとその章へ飛ぶ。Q5)
  1. はじめに / 2. 正体 / 3. 生息地の環境 / 4. 繁殖記録の比較 /
  5. 飼い方・殖やし方 / 6. 買う前に知っておくこと / 7. まだ分かっていないこと / 参考文献

[h2] 1. はじめに（このページの読み方）
     情報源の種類、要確認・未確認・近縁種のデータ・（推論）の意味（FR1.7）
[h2] 2. 正体（名前・分類・似た種）
[h2] 3. 生息地の環境（水系・水質・季節・底質・同じ場所にいる魚）
[h2] 4. 繁殖記録の比較
     [繁殖記録の表] (FR1.3)
       誰が | いつ | どんな水で | きっかけ | 卵の数 | 孵化までの日数 | 稚魚の育て方 | 失敗例 | 出典
     記録が1件もないとき:「繁殖の記録はまだ見つかっていません。」
[h2] 5. 飼い方・殖やし方（記録から導いたもの）
[h2] 6. 買う前に知っておくこと（流通・価格・合法性と規制・雌雄の見分け方）

     分類ごとの番号付きリスト。各項目に id（ref-1 など）を付ける（FR1.4）

本文の［12］ -> 押すと参考文献の 12 番へ移る (FR1.4)
--------------------------------------------------------------
[フッター] 情報は各ページの更新日時点のものです。飼育は自己責任でお願いします。
           更新履歴 / 用語集 / 比較 へのリンク
```

## 2. ゼブリーナ（CW111）の並べ直し

今の章を、型の章に次のように移します。

| 今の章・小見出し | 新しい章 |
|---|---|
| はじめに ― このガイドの作り方 | 1. はじめに（「このガイド」の呼び方は「このページ」に直す） |
| 1. ゼブリーナの正体（未記載種、名前、Hoplisoma、CW146） | 2. 正体 |
| 2. 故郷の環境（産地、水、生息地の状況） | 3. 生息地の環境 |
| （なし） | 4. 繁殖記録の比較 — 有料ガイドの原稿と調査レポートから移す（Q2） |
| （なし） | 5. 飼い方・殖やし方 — 有料ガイドの原稿と調査レポートから移す（Q2） |
| 3. 買う前に知っておくこと（歴史、価格、相場、ブリードをすすめる理由、合法性、血統、雌雄、導入直後のリスク、水合わせ） | 6. 買う前に知っておくこと |
| （本文中に散らばっている「分かっていない」こと） | 7. まだ分かっていないこと — 本文の「未確認」「要確認」と、分かっていない点を集める |
| 飼育と繁殖の詳しい章について（有料の案内） | 外す（FR2.2） |
| 参考文献（48件） | 参考文献（移した章で増える分を足す） |

**Q2 による要件の変更**: 要件 FR2.1 は「中身は今のものを使い、削ったり書き換えたりしない」でしたが、Q2 で「繁殖記録の比較」と「飼い方・殖やし方」は有料ガイドの原稿（`guide/`）と調査レポート（`../kabu-buysell/reports/`）から移して無料で載せることになりました。今の本文の事実・数字・出典は削らず、2つの章を足します。移すときは、数字と引用を原文で確かめ直し、本人が確認します（project.md の Mandated）。

## 4. 種の一覧ページ（`/species/`）

- 見出しは「種の一覧」（FR3.2）。
- 種のカードを、和名の五十音順で並べる（code-quality-assessment F8 の並び順を決める。理由: 種が増えても探しやすい）。

## 5. 比較ページ（`/compare/`）

種ごとの要約を1行ずつ並べ、詳しくは各種のページへ（Q6、FR4.3）。

```
[h1] 種をまたいだ比較
[説明] 各種のページの「繁殖記録の比較」から、要約だけを並べています。
[要約の表]
  種（リンク） | 繁殖記録の件数 | 孵化までの日数の幅 | 卵の数の幅 | 水温の幅 | 更新日
  ゼブリーナ（CW111） | n 件 | x〜y 日 | ... | ... | 2026-11-16
[種が1つのとき] 表の下に「いまは1種だけです。種が増えると並びます。」
```

<!-- Text fallback: 比較ページは見出し、説明、種ごとに1行の要約表の順。種が1つのときは一言添える。 -->

- 要約の数字は各種のページの繁殖記録の表から作る。手で別に書かない（同じ事実を2か所に書かない）。

## 6. 用語集ページ（`/glossary/`）

- 用語を五十音順に並べ、各用語に id を付ける（他のページからリンクできるように）。
- 最初の用語: CW 番号、未記載種、ワイルド、ブリード、F1・F2、要確認、未確認、近縁種のデータ、（推論）、ブラックウォーター・クリアウォーター（FR4.2）。

## 7. 更新履歴ページ（`/updates/`）

- 種ページと付属ページを、更新日の新しい順に自動で並べる（FR4.1、Q8 of requirements）。
- 各行: 更新日 / ページ名（リンク）/ 公開日。

## Assumptions & Open Questions

- 有料ガイドの原稿（`guide/`）の中身はまだ開いていない。移す範囲と出典の数は、実装の段階で原稿を開いてから決める。
- 種の一覧の並び順（五十音順）は、設計で決めた案。変えたいときは承認のときに言ってもらう。
