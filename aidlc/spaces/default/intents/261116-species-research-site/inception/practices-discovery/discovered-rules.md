# 必ず守るルール

## Mandated

- ALWAYS 数字には［番号］で出典を付け、巻末の参考文献の番号と対応させる
- ALWAYS YouTube の自動字幕や伝聞から拾った情報には「要確認」と書く
- ALWAYS 元の資料を開けず裏が取れない情報には「未確認」と書く
- ALWAYS 近縁種の数字には「近縁種のデータ」、筆者の解釈には「（推論）」と書く
- ALWAYS 分かっていないことは、分かっていないと明記する
- ALWAYS AI が出した引用と数字は、公開する前に必ず原文で確かめる
- ALWAYS 他の人の記録は引用して自分の言葉でまとめ、AI がまとめた記載は本人が確かめる
- ALWAYS 原文を引用するときは短い一文までにとどめ、「」で囲んで出典を付ける
- ALWAYS 情報提供者や海外の研究プロジェクト・データベースの記録や写真を使うときは、先に使用の許可をもらう
- ALWAYS 写真は自分で撮ったものか、許可を得たものだけを使う
- ALWAYS ワイルド個体の合法性については、分かることと分からないことを分けて書く
- ALWAYS 日本の規制（外来生物法など）は種類ごとに確かめて書く
- ALWAYS 広告やアフィリエイトを入れるときは「広告」と表示する
- ALWAYS 本公開の日までは、全ページに noindex を付けたままにする
- ALWAYS `site/` を変えたら `hugo` で `docs/` に書き出し、`site/` と `docs/` を同じコミットに入れる

## Forbidden

- NEVER ワイルド個体の合法性を断定する
- NEVER 販売店をおすすめする（店のページを出典に使うときは、推奨ではないと断る）
- NEVER 他サイトの文章・写真・論文の図を許可なく転載する
- NEVER 有料ガイドの原稿（`guide/`）を公開リポジトリに入れる
- NEVER `docs/` を手で編集する
